# Rent-analysis-germany
# Rent Affordability Analysis in Germany 🇩🇪
This project was developed as part of my Data Analysis training program, focusing on real-world data analysis using Python, SQL, and Power BI.

## 📊 Overview
This projectanalyse  housing affordability in Germany by comparing rent, income, and population data across different federal states (Bundesländer) between 2018 and 2020.

## 🛠 Tools & Technologies
- Power BI (Dashboard & Data Visualization)
- Python (Pandas, NumPy for data cleaning and analysis)
- SQL (data querying and transformation)

## 📌 Key Analysis
- Rent per square meter (€/m²) by state
- Income vs rent comparison
- Rent burden (rent-to-income ratio)
- Population and housing development trends

## 📈 Insights
- Identification of regions with high rent pressure
- Relationship between income and housing costs
- Regional differences in affordability across Germany

## 📂 Project Structure
- `dashboard.pbix` → Power BI dashboard
- `dataset.csv` → Source data
- `analysis.ipynb` → Data analysis in Python (optional)

## 🎯 Goal
To support data-driven insights for understanding housing affordability and regional differences in Germany.

# 🇩🇪 Analyse der Wohnkostenbelastung in Deutschland

## 📊 Übersicht
Dieses Projekt analysiert die Wohnkostenbelastung in Deutschland durch den Vergleich von Miete, Einkommen und Bevölkerungsdaten in verschiedenen Bundesländern (2018–2020).

## 🛠 Verwendete Technologien
- Power BI (Dashboard & Visualisierung)
- Python (Pandas, NumPy zur Datenaufbereitung)
- SQL (Datenabfragen und Transformation)

## 📌 Analyseinhalte
- Miete pro Quadratmeter nach Bundesland
- Vergleich von Einkommen und Miete
- Mietbelastung (Verhältnis Miete zu Einkommen)
- Entwicklung von Bevölkerung und Neubautätigkeit

## 📈 Erkenntnisse
- Identifikation von Regionen mit hoher Mietbelastung
- Zusammenhang zwischen Einkommen und Wohnkosten
- Regionale Unterschiede in der Wohnkostenbelastung

## 🎯 Ziel
Unterstützung datenbasierter Entscheidungen im Bereich Wohnkostenanalyse und Marktverständnis in Deutschland.
