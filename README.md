# Rent Affordability Analysis in Germany 🇩🇪

This project was developed as part of my Data Analysis training program, focusing on real-world data analysis using Power BI.

---

## 📊 Overview

This project analyzes housing affordability in Germany by comparing rent, income, and population data across different federal states (Bundesländer) between 2018 and 2020.

---

## 🛠 Tools & Technologies

- Power BI (Dashboard & Data Visualization)
- Excel / CSV (Data source)

---

## 📊 Power BI Dashboard

The interactive dashboard was developed using Power BI to analyze rent affordability across Germany.

Download the file from this repository to explore the dashboard.

---

## 📌 Key Analysis

- Rent per square meter (€/m²) by state  
- Income vs rent comparison  
- Rent burden (rent-to-income ratio)  
- Population and housing development trends  

---

## 📈 Insights

- Berlin, Hamburg, and Baden-Württemberg exhibit significantly higher rent burden compared to other regions  
- Strong regional disparities in housing affordability across Germany  
- Urban areas tend to have higher rent-to-income ratios compared to less populated regions
-  Analysis of the relationship between rent and income, highlighting the rent-to-income ratio as a key affordability indicator
- Investigation of the impact of housing construction (new dwellings) on rent levels
- In large cities like Hamburg, high construction activity does not necessarily lead to lower rent pressure.
- Despite increased housing supply, rent burden remains high, suggesting strong demand and structural imbalances in urban housing markets.

# 🇩🇪 Analyse der Wohnkostenbelastung in Deutschland

Dieses Projekt wurde im Rahmen meiner Weiterbildung im Bereich Data Analysis erstellt und fokussiert sich auf praxisnahe Datenanalyse mit Power BI.

---

## 📊 Übersicht

Dieses Projekt analysiert die Wohnkostenbelastung in Deutschland durch den Vergleich von Miete, Einkommen und Bevölkerungsdaten in verschiedenen Bundesländern (2018–2020).

---

## 🛠 Verwendete Technologien

- Power BI (Dashboard & Visualisierung)
- Excel / CSV (Datenquelle)

---

## 📊 Power BI Dashboard

Das interaktive Dashboard wurde mit Power BI erstellt, um die Wohnkostenbelastung in Deutschland zu analysieren.

Die Datei kann im Repository heruntergeladen werden.

---

## 📌 Analyseinhalte

- Miete pro Quadratmeter (€/m²) nach Bundesland  
- Vergleich von Einkommen und Miete  
- Mietbelastung (Verhältnis Miete zu Einkommen)  
- Entwicklung von Bevölkerung und Wohnungsbau  

---

## 📈 Erkenntnisse

- Berlin, Hamburg und Baden-Württemberg weisen eine deutlich höhere Mietbelastung auf  
- Starke regionale Unterschiede in der Wohnkostenbelastung in Deutschland  
- Urbane Regionen zeigen höhere Miet-Einkommens-Verhältnisse als ländliche Gebiete
